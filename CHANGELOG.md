# Changelog

## 0.1.0 — Initial release

- Modular extension scaffold with a local, read-only PDF utility.
- PDF reading, outline, thumbnails, search, zoom, rotation, refresh, and view state.
- Page-cited clipboard text, extraction preview, and explicit Markdown export.
- Three bounded, workspace-aware Copilot PDF tools.
- Background extraction, cancellation, limits, and canonical-path access checks.
- Automated checks, browser/host tests, dependency updates, CodeQL, and OIDC release workflow.
